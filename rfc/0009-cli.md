# CLI

## Commands

### Run

To run the preprocessor, lexer, parser, and evaluator on a file...

```
church run <filename>
```

To also simplify the output...

```
church run <filename> --simplify
```

or

```
church run <filename> -s
```

### Prep

To only run the preprocessor and output to the stdout.

```
chruch prep <filename>
```

## Notes

NOTE: This should be done using the crate clap. The derive pattern is preferred to the builder pattern.
